Om meg

Diar Ali

Jeg heter Diar Ali og er student ved Høgskulen på Vestlandet (HVL), hvor jeg studerer informasjonsteknologi. Jeg er interessert i teknologi, programmering og utvikling av nettsider. Jeg liker å lære nye ting og jobbe med praktiske oppgaver som gir meg erfaring.

Jeg er en engasjert og motivert person som liker å samarbeide med andre. Jeg synes det er spennende å se hvordan digitale løsninger kan brukes i virkelige prosjekter, og jeg ønsker å utvikle ferdighetene mine videre innen webutvikling og programmering.

Utdanning

Informasjonsteknologi

Jeg studerer informasjonsteknologi ved HVL. Gjennom studiet får jeg kunnskap om programmering, webutvikling og digitale løsninger. Jeg lærer blant annet HTML, CSS og Java, og hvordan man kan bygge og utvikle nettsider. Målet mitt er å utvikle gode tekniske ferdigheter og få mer erfaring med programmering og webutvikling.

Mitt arbeid i prosjektet

Innvendig og oppussing

I prosjektet Boligbyen Bergen A/S har jeg jobbet med sidene som handler om innvendige løsninger og oppussing. Jeg har arbeidet med å lage og organisere innhold, skrive tekster, bruke bilder og sørge for at informasjonen presenteres på en enkel og oversiktlig måte.

Dette arbeidet har gitt meg praktisk erfaring med hvordan man kan bygge en nettside som er brukervennlig og informativ, og hvordan ulike sider fungerer sammen. Jeg har også fått bedre forståelse for hvordan HTML og CSS brukes til å strukturere og utforme en nettside.

Mine mål

Erfaring og videre utvikling

Jeg ønsker å fortsette å utvikle ferdighetene mine innen informasjonsteknologi. Fremover vil jeg bli bedre på programmering og webutvikling, og lære mer om hvordan digitale løsninger kan utvikles. Jeg ønsker å bruke kunnskapen jeg får gjennom studiet til å få mer praktisk erfaring og utvikle ferdigheter som jeg kan bruke i fremtidige prosjekter og arbeidslivet.
